# Дорогами памяти

Интерактивный путеводитель по 30 памятным местам Беларуси — по пять в каждой области. Каждое место показано в трёх временах: **Прошлое** (история с источником под каждым блоком), **Настоящее** (фототур с точками, панорама 360°, аудиорассказ, как добраться), **Будущее** (предложение по сохранению с визуализацией «Сейчас / Предлагаем»).

Разделы: карта, страница места, герои (24 человека), «Голоса и документы» (архив), викторина, «Мой маршрут». Интерфейс на русском и белорусском языках.

## Запуск

Сборка не нужна — откройте `index.html` в браузере.

- Всё, кроме панорам, работает **без интернета**: карта, фото, аудио, тексты.
- **Панорамы 360°** — виджет Яндекс Карт, нужен интернет. Без сети вместо панорамы показывается сообщение, фототур работает.
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. Все пути относительные.

## Структура

```
index.html        разметка, иконки, встроенная SVG-карта Беларуси
styles.css        стили (дизайн-токены в начале файла)
i18n.js           строки интерфейса RU/BE, t() и L()
data.js           места, герои, архив, викторина, фото, точки фототуров, панорамы
credits.js        авторы и лицензии всех снимков (из метаданных Wikimedia Commons)
narration.js      тексты аудиорассказов (RU/BE)
app.js            логика: роутинг, карта, фототур, панорамы, аудио, формы, викторина, маршрут
CREDITS.md        список авторов и лицензий в читаемом виде
fonts/            Inter, Oswald, Playfair Display (локально)
images/
  places/<id>-cover.jpg, <id>-tour-N.jpg   фото мест
  heroes/                                  портреты героев
  archive/                                 архивные снимки
  placeholder.svg                          заглушка
audio/
  places/<id>.mp3   рассказ о каждом месте (30)
  heroes/<id>.mp3   рассказ о каждом герое (24)
  *-levitan-*.mp3   архивные записи Юрия Левитана
```

## Как добавить материалы

- **Фото и фототур** — файл в `images/places/`, запись в `PHOTOS` (data.js), автор — в `credits.js`. Точки задаются в процентах кадра (`x`, `y`). Надписи на памятниках (`ins`) пишутся в оригинале и не переводятся.
- **Панорама** — запись `PANORAMAS.<id> = { point: [долгота, широта], dir: азимут }`. Точку можно взять из ссылки «Поделиться» на панораме Яндекс Карт.
- **Статус предложения** — `future.status` у места (`idea` / `discussing` / `agreed` / `done`), стоимость — `future.cost`.
- **Тексты** — у каждого поля два языка: `T('рус', 'бел')`.

Правило проекта: если сведений нет — пишем «Уточняется», ничего не выдумываем.

## Источники

| Материал | Источник |

| Фото мест, портреты, архивные снимки (120 файлов) | Wikimedia Commons; автор и лицензия каждого — в [CREDITS.md](CREDITS.md) и в подписи на сайте |

| Архивное аудио (Ю. Левитан) | источник файлов уточняется |

## Что ещё не готово

- Современные фото есть у 21 из 30 мест, у Раковичей — архивный снимок 1944 года. Для Дремлёво, Рыленок, Партизанской кринички, Шауличей, Кургана Славы в Гродно, Зыслова, Борок и Усакино свободных снимков нет ни на Wikimedia Commons, ни на Wikimapia — у них иллюстрация и кнопка «Предложить фото»; у Борок, Рыленок и Кургана Славы в Гродно есть панорама 360°.
- У 5 героев (Каминский, Лобанок, Кживонь, Кутепов, Виниченко) свободных портретов нет — показан связанный с ними памятник с пояснением.
- Аудио записано только на русском (белорусского голоса у синтезатора нет); текстовая версия есть на обоих языках.
- Формы сохраняют материалы только в браузере (`localStorage`), сервера нет.

## Данные в браузере

`dp_lang` — язык, `dp_route` — маршрут, `dp_opened` — открытые места, `dp_achievements` — достижения, `dp_quiz_best` — рекорд викторины, `dp_submissions` — отправленные материалы.
